# AI Builds: Garima's portfolio

A one-page portfolio of six products I designed, built and shipped independently with Claude and Claude Code:

| Project | What it is |
|---|---|
| [Signal Desk](https://signal-desk-uk.vercel.app) | Monthly UK private-markets signal feed from 5.7M Companies House records, refreshed by GitHub Actions |
| [Pipeline Truth](https://pipeline-truth.vercel.app/?demo) | Forecast health check for Salesforce exports, with a privacy-first Claude summary |
| [Robot-Ready](https://robot-ready.vercel.app) | Go-live readiness kit for AI picking robots, with a Claude-written memo |
| [Pipeline from Scratch](https://pipeline-from-scratch.vercel.app) | First outbound playbook for a seed-stage AI-native CRM |
| [UK Buy-to-Let Returns Lab](https://btl-returns-lab.vercel.app) | 10-year returns model on official UK data, web + Excel |
| [Bid Multipliers](https://bid-multipliers-se.vercel.app) | Partner ecosystem map for AI tender analysis in Swedish construction |

Live: https://garima-ai-builds.vercel.app

Static page, no build step: `index.html` plus screenshots in `img/`.
