Signal Desk

A monthly feed of who is launching funds and setting up deals in the UK, pulled straight from the Companies House register.

  • Scans 5.7M register entries and finds 3,498 fund partnerships, carry vehicles and BidCo/TopCo deal stacks in 12 months
  • Groups them into 585 sponsor clusters, with an interactive monthly chart and a filterable feed
  • Refreshes itself every month through a scheduled GitHub Action; ships with a full outbound playbook

AI in the build: designed the classification rules with Claude, then used Claude Code to write and test the data pipeline and site.

Pipeline Truth

A free health check for sales forecasts: drop in a Salesforce export and see how much pipeline rests on stale data.

  • 5 rule-based checks and a value-weighted score, with stage, owner and forecast views plus a fix-list export
  • An optional Claude-written brief that only ever sees aggregates, with rep names replaced by labels
  • Ships with the full PRD: user stories, acceptance criteria, metrics and an AI decision log

AI in the product: Claude API behind a serverless function, with data minimised before it leaves the browser.

UK Buy-to-Let Returns Lab

Personal name or limited company? A 10-year returns model for UK rental property.

  • Built on HM Land Registry prices, ONS rents and current HMRC tax rates
  • IRR in 13 currencies for overseas investors, plus a regional ranking
  • A matching Excel model, checked line by line against the web version

AI in the build: Claude Code to build and cross-check both models; every tax rule traced to GOV.UK.
